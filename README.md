# Number Guessing Game

A simple Python game where the computer picks a random number between 1 and 100, and you try to guess it. The game tells you if your guess is too high or too low, and counts how many attempts it took you to get it right.

## How to run

python main.py

## Example

Guess a number between 1 and 100: 50
Too high.
Guess a number between 1 and 100: 25
Too low.
Guess a number between 1 and 100: 37
Correct! You got it in 3 guesses.
